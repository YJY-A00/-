
# 个人网站搭建全记录

> 从零开始，搭建一个运行在海外服务器上的个人博客网站。整个过程涉及域名购买、服务器配置、环境搭建、网站部署与运维，适合作为 Linux 运维 / 建站入门的实践项目。

---

## 📌 项目背景

- **初衷**：搭建一个属于自己的个人网站（博客/作品集），用于学习 Linux 运维和网站部署流程。
- **核心诉求**：
  - 使用海外服务器，**避免国内 ICP 备案**流程
  - 成本控制在极低水平（域名首年 ¥10.30，服务器约 ¥28/月）
  - 技术栈简单，适合新手实操

---

## 🛠 技术选型

| 模块 | 选择 | 理由 |
| :--- | :--- | :--- |
| 域名注册 | Dynadot | 支持支付宝，首年价格便宜 |

## ✅ 已完成的实施步骤

以下是我从零开始，一步步完成的所有操作。


### 阶段一：域名购买

**状态：✅ 已完成**

1. 在 [Dynadot](https://www.dynadot.com) 注册账号并搜索域名 `yjyzy.lol`
2. 加入购物车并完成支付（首年 ¥10.30）
3. 购买后在 DNS 设置中添加 **A 记录**，指向后续购买的服务器 IP

> **收获**：了解了域名注册流程、DNS 解析原理（A 记录、CNAME 记录的区别）


### 阶段二：服务器购买与配置

**状态：✅ 已完成**

1. 在阿里云购买 **新加坡节点** 的轻量应用服务器
   - 初始配置：2 vCPU / 0.5 GiB（后因内存不足升级至 **1 GiB**）
   - 操作系统：Ubuntu 22.04 LTS
2. 在阿里云控制台放行必要端口：`22`、`80`、`443`、`8888`、`11908`
3. 通过 **SSH** 和 **VNC（管理终端）** 连接服务器
4. 执行宝塔面板安装脚本：

```bash
if [ -f /usr/bin/curl ];then curl -sSO https://download.bt.cn/install/install_panel.sh;else wget -O install_panel.sh https://download.bt.cn/install/install_panel.sh;fi;bash install_panel.sh ed8484bec
收获：掌握了云服务器购买流程、安全组配置、远程连接方式（SSH / VNC）


### 阶段三:搭建网站运行环境（宝塔面板 + LNMP）

**状态：** ✅ 已完成

1. 登录宝塔面板（访问 `https://IP:11908`）
2. 在“软件商店”一键安装 **LNMP 环境**（Nginx + MySQL + PHP）
3. 由于初始服务器内存较小（0.5 GiB），编译安装 PHP 时多次卡死
4. 升级服务器内存至 **1 GiB**
5. 改用 **“极速安装”**（预编译包），而非“编译安装”

> **收获**：理解了编译安装与极速安装的区别，学会了用 `top` / `free` / `ps aux` 命令排查资源瓶颈


### 阶段四：创建站点并部署 WordPress（Docker 方式）

**状态：** ✅ 已完成

1. 在宝塔面板“网站”模块创建站点，绑定域名 `yjyzy.lol`
2. 通过“软件商店”搜索并部署 **WordPress（Docker 应用）**
3. 在“域名管理”中绑定 `yjyzy.lol`
4. 访问 `http://yjyzy.lol` 或 `http://47.237.144.216:18040` 可看到 WordPress 安装界面

> **收获**：学会了宝塔面板的站点管理、Docker 应用的部署流程，理解了端口映射和域名绑定的概念


### 阶段五：域名解析配置

**状态：** ✅ 已完成

1. 在 Dynadot 将 A 记录指向服务器 IP：`47.237.144.216`
2. 等待 DNS 解析生效（约 10-30 分钟）
3. 访问 `http://yjyzy.lol`，成功看到 WordPress 安装界面

> **收获**：完整实践了“域名 → DNS → 服务器 → 站点”的全链路解析过程
